# Playbook วันเพิ่ม Provider / Local AI (เฟสภายหลังตาม DEC-165)

จัดทำ 25 ต.ค. 2026 — ผู้ใช้ยืนยัน: **ยังไม่เพิ่มตอนนี้ แต่จะเพิ่มแน่นอนภายหลัง รวมถึง AI local บนเซิร์ฟเวอร์ปรับใช้จริง** เอกสารนี้เตรียมไว้ให้วันนั้น "เปิดปุ๊บ ทำได้เลย" — จนกว่าผู้ใช้เปิดหัวข้อ agent ห้ามเปิด/ทดสอบ/ถามซ้ำ

## ส่วน A — เพิ่ม API Provider (เช่น OpenRouter/Zen/Groq/เจ้าใหม่)

**ของที่ต้องเตรียมก่อนเริ่ม (~10 นาที):**
1. API key ของ provider นั้น + หลักฐานว่าเป็น Free tier จริง (หน้า billing/pricing ของบัญชี — จะใช้ต่ออายุ attestation ทุก ≤30 วันตามระบบ)
2. รู้จักโมเดลตัวที่จะใช้ + ราคาต่อล้าน token (ระบบ FREE_ONLY จะบล็อกโมเดล unknown/paid จนกว่า pricing ถูกตรวจแล้ว)
3. เช็คว่าโมเดล **รองรับ strict JSON output** (ถ้าไม่รองรับ จะใช้เป็นตัวตอบ assistant ไม่ได้ — บทเรียนจาก DEC-164)

**ขั้นตอน (ทำเองบน UI ได้ทั้งหมด ไม่ต้องแตะโค้ด):**
1. Dashboard → บริการ AI → เพิ่ม provider (ชื่อ/adapter/URL + key)
2. เพิ่มโมเดล + กดทดสอบ → ดูผล HTTP/เวลา ต้อง 200 ภายใน ~25 วิ
3. ต่ออายุ Free-account permission (Settings → Free account) ด้วยหลักฐานจากข้อ 1
4. **คุณภาพ (สำคัญ):** สั่ง agent รัน quality bracket — ชุดเคสตัวแทน 7 เคสบน harness เดิม (แบบที่ Gemini Lite ผ่าน 29/30+19/20) ก่อนเปิดเป็นตัวตอบหลัก/สำรอง — ผ่านค่อยเปิด enabled + จัดลำดับ
5. บันทึกใน decision log + อัปเดตบอร์ดงาน

**กติกาคงที่:** ห้าม paid โดยไม่เปิด ALLOW_PAID ผ่าน UI อย่างชัดเจน · ห้ามหมุน key หลบ quota · ทุกโมเดลเริ่ม disabled ก่อนเสมอ

## ส่วน B — Local AI บนเซิร์ฟเวอร์ (เมื่อมี host จริง)

**แนวทางเลือกขนาด (อ้างอิงทั่วไป ปรับตามงบ):**

| ทางเลือก | สเปคขั้นต่ำโดยประมาณ | ได้อะไร |
|---|---|---|
| โมเดลเล็กเฉพาะงานช่วย (เช่น embedding/จัดหมวด) | CPU ระดับเดียวกับที่รัน E5 ปัจจุบัน (4 core/8GB) | เสริมงานเบื้องหลัง ไม่ตอบนักศึกษา |
| LLM ตอบคำถาม 3–8B (quantized) | RAM 16–24GB หรือ GPU 8–12GB VRAM | ตอบพื้นฐานได้ คุณภาพไทยต้องวัดจริงก่อนใช้ |
| LLM เจาะจงคุณภาพไทยสูง | GPU 24GB VRAM+ | ต้นทุนสูง แนะนำเมื่อมีผู้ใช้จริงมั่นคง |

**หลักเหนี่ยวรั้งเดิมที่จะยังใช้:** ทุกโมเดลท้องถิ่นยังต้องผ่าน quality bracket เดียวกับ API · ยังอยู่หลัง Gateway/FREE_ONLY เดิม (local = ฟรีโดยนิยาม แต่ยังต้องลงทะเบียนในระบบเพื่อสั่งลำดับ/เปลี่ยนได้จาก UI) · ไม่เปิดบนเครื่องพัฒนา (สเปคไม่พอ — DEC-165)

**แนวทางติดตั้งบน host:** รันเป็นบริการคู่ข้าง app (คล้าย E5 ปัจจุบัน: process แยก + health check + offline weights) — เมื่อถึงวันนั้น agent จะเตรียม service + bridge ตามแพตเทิร์น [hermes bridge](../../lib/ai/hermes-pilot-bridge.ts) ให้

## ส่วน C — สิ่งที่ agent เตรียมต่อให้ทันทีเมื่อคุณสั่งเปิดเฟสนี้

- ตรวจ registry + attestation รอบใหม่ทั้งหมด (สคริปต์พร้อมแล้ว: `scripts/ai/renew-gemini-free-grant.ts` เป็นแม่แบบ)
- รัน quality bracket 7 เคสตัวแทนบน harness เดิม (ไม่ pool คะแนนกับ Gemini)
- ถ้าผ่าน: จัดลำดับเป็นสำรองหลัง Gemini Lite → จากนั้นเปิดทาง Hermes Staff Copilot ตามแผน EXT-04
