## Existing architecture and chosen boundaries

Keep existing families/documents/version streams/chunks/cohorts and family→document publication locks. Import creates data/version records and uses existing seven-dataset registry after M8, never automatic DDL. The existing plan stores immutable original bytes encrypted in a private import job; a private Supabase Storage backend is the production original-storage target. Both must obey the same opaque original reference/checksum/authorization contract; an unimplemented Storage backend is not reported as accepted. Staged extracted text/analysis stays encrypted and unpublished. Do not use a public bucket or raw filesystem/URL reference as permission.

Upload and official URL acquisition share `ImportSource`: immutable bytes, detected format (PDF/DOCX/XLSX/CSV/HTML), display filename, nullable reviewed source URL, original acquisition URL/fetch time and SHA256. URL is an input method, not a sixth binary format. Uploaded files can have missing provenance during staging; PUBLIC approval requires reviewed official provenance. A fetch time cannot become an effective/published date.

`Extraction` preserves page number for PDFs and nullable page number where a parser cannot prove pagination, section/heading information, worksheet/row/table references, text, tables and per-page review warnings. Tables preserve exact strings/blank cells; no inferred fees/dates or spreadsheet formula evaluation. Supported binary parsers run in an isolated bounded child outside SQL with fixed argv/stdin; no uploaded filename in a shell, external resources/scripts/macros/XML entities disabled, archive expansion bounded. Low text/scanned/broken-font/unsupported-table/formula/hidden-data warnings require review; do not make a clean-quality claim from a title or successful parse alone.

Limits: original20MiB, extracted5M characters/1000pages, 2000chunks (existing chunker), 1000tables/100000total cells, 10000rows/table/256columns, cell10000characters. Binary parsing total15s, 256MiB JS heap, bounded stdout32MiB and fixed sanitized error output. Acquisition total10s, original20MiB, only HTTPS official `yru.ac.th` or its subdomains, no userinfo/query credentials/non443/fragment/IP/local names, fresh public IPv4/IPv6 resolution and socket pinning; at most3redirects revalidated before DNS/connect. External archive Google Drive links are staging warnings/manual sources, not a reason to make URL import an unrestricted proxy. Private originals persist across parse failure and never auto-publish.

Office parser boundary limits are additional resource limits, not inferred document quality: ZIP has2000entries/16MiBperpart/64MiBtotal, rejectsZIP64/active/nested parts and verifies actual sizes+CRC. XML permits UTF8/XML1.0 only, with16MiBinput/100000elements/depth64/256attributes/5Mtext+attributecharacters and **200000ordered nonempty text/CDATA segments**; the segment cap prevents allocation overhead independently of character count. Package XML aggregation caps250000elements/10Mtext+attributecharacters and2000relationships. Exceeding a boundary fails extraction with original retained; no truncation or partial clean output. Ordinary supported Office text/tables and Strict/Transitional namespaces are tested separately; uncommon/unsupported features require review or fail closed. These are root implementation policies within the bounded-parser requirement, not user-selected numerical limits.

### Frozen original reference/access contract (IMP-N1)

Server-only `OriginalRef` fields: `id:UUID`, `backend:PRIVATE_DATABASE|PRIVATE_STORAGE`, `byteLength:1..20MiB`, `format`, immutable `checksum:SHA256`, `keyVersion:1`. Display filename/provenance stay separate. API list/preview returns import-job ID and reviewed metadata, never ciphertext, storage object key, service token or a public/durable signed URL. Active SUPER_ADMIN is checked again immediately before backend streaming original bytes and `KNOWLEDGE_ORIGINAL_READ` records actor/job ID/byte count only. Ordinary Staff/browser storage reads are denied even with a guessed object ID; content may be streamed only through the authenticated same-origin backend endpoint with private no-store caching.

Both backends use application AES-256-GCM for original bytes, a fresh12-byte nonce,16-byte tag and authenticated job/original ID+checksum context. Key material is server `ENCRYPTION_KEY`; `keyVersion` is a format/key-rotation discriminator, not a key or username. Rotation requires a reviewed explicit operation retaining the old key until every affected object verifies re-encryption; no automatic rotation/delete worker is authorized. Storage bucket `knowledge-originals` is private, no anon/authenticated object policies, upload never upserts; server opaque object key derives only from UUIDs, not filename/source. DB staging stores the same encrypted envelope privately. Failed/abandoned/orphaned originals remain retained indefinitely until an explicit authorized retention/deletion operation is designed; current implementation must not delete remote originals to make retries work.

### Source location, warnings and catalogs (IMP-N2/N4/N5)

Location is a discriminated record preserved through parser→staging→chunk/dataset→citation: PDF page+block/table index; DOCX stable block/table index+heading path with no fabricated page; XLSX sheet name/index+row/column range+table index; CSV logical record/column range+table index; HTML final sanitized source URL+stable block index+heading path+table index. Existing `pageNumber/sectionTitle` remain compatibility views. Missing location during intermediate contract work is a blocking provenance warning, never publication acceptance. M7 must add persisted chunk source-location and citation/delivery equality before claiming format provenance.

`ExtractionReport` carries schema version1, parser name/version, input byte count, page/table/cell/text/replacement counts, truncation boolean and bounded warning records `{code,severity:BLOCKING|REVIEW,location,count,disposition:UNRESOLVED|CORRECTED|FALSE_POSITIVE}`. Initial disposition UNRESOLVED; review disposition records actor/revision/reason and original warning, cannot erase evidence. PUBLIC refuses unresolved/blocking quality/provenance/sensitivity warnings. Redaction/reanalysis yields a new extraction checksum/revision while immutable original checksum remains unchanged; false-positive disposition never authorizes detected unredacted personal data. Detector output is risk evidence, not proof that a file contains no personal data. Actual per-format quality/locations/report are required before parser acceptance; initial pure modules are partial contracts.

Fixed dataset codes exactly `academic_calendar_events`, `tuition_fees`, `transfer_courses`, `university_services`, `university_systems`, `service_forms`, `announcements`; backend maps code to its installed validated mapper, no raw table name from input. M7 publication cannot choose BOTH/STRUCTURED while its installed mapper is absent. All19 initial family codes from master§64 are a seed/coverage acceptance: ACADEMIC_CALENDAR, REGISTRATION_GUIDE, TRANSFER_REGULATION, TRANSFER_GUIDE, TRANSFER_COURSE_TABLE, TUITION_FEE, EXAM_REGULATION, GRADING_REGULATION, TRANSCRIPT_GUIDE, CERTIFICATE_GUIDE, COURSE_WITHDRAWAL_GUIDE, SPECIAL_COURSE_GUIDE, WIFI_GUIDE, YRU_PASSPORT_GUIDE, MICROSOFT_365_GUIDE, LIBRARY_GUIDE, STUDENT_ACTIVITY_RULE, VOLUNTEER_ACTIVITY_RULE, DORMITORY_RULE. Family suggestions remain proposals; authenticated reviewer resolves unknown/conflicting family.

Resource enforcement distinction (IMP-N6): Node heap cap bounds V8 heap, not total RSS/ArrayBuffer/native allocations. A child process provides termination/isolation, not an OS filesystem/network sandbox. Production deployment must supervise parser RSS/CPU/network/filesystem access; until that evidence exists, report this gate pending. Locally bound original/expanded archives/stdout/time and terminate on abort; reject duplicate/nested/oversized ZIP entries before parsing. URL acquisition rejects the entire A/AAAA answer mixture if any address is non-public, revalidates every redirect and bounds streamed decoded bytes, not just declared Content-Length.

## Analysis and review

Deterministic analyzer proposes title, document type, department/family/version/year and fixed dataset candidate using explicit extracted text. Conflicting or absent evidence yields null and warnings. Published/effective dates and authority start null for human review. It detects known sensitive categories and emits safe category codes, never copies matched personal details into logs/audit. Suggestions are not approval, final department routing or proof of authority.

Classification distinguishes narrative/table/mixed source. A backend-installed recognized schema permits STRUCTURED/BOTH; absent/unknown schema proposes RAG with `STRUCTURED_SCHEMA_UNAVAILABLE`. Keep the table and candidate in preview for M8 review rather than losing exact cells. Dataset identifiers are fixed to the seven specification datasets; no caller/AI supplied SQL table name.

Preview exposes staged pages/chunks/table candidates, warnings, proposed metadata and existing family/current stream/version conflicts only to active SUPER_ADMIN. Root final review schema requires reviewed title/department/family/version/type/stream/scope/year/dates/authority/provenance/sensitivity and explicit attestations. Actions exactly NEW_FAMILY, ADD_ADDITIONAL, REPLACE_CURRENT, ADD_HISTORICAL, AMEND_EXISTING; target+revision required for relevant existing-document actions. Do not precheck attestations. PUBLIC refuses unresolved sensitivity, source, extraction or applicability warnings. Sensitive extracted content must be redacted/reanalyzed or retained INTERNAL/RESTRICTED under the existing permissions; an acknowledgment alone does not make detected personal data PUBLIC.

Before cancellation, historical as-of retrieval still returns the formerly applicable rule. Partial/provision-level cancellation is unsupported for automatic publication and stays PENDING_REVIEW. Test two active amendments/inactive/out-of-date/audience mismatch/cancel-one/cancel-base/historical before/after, without changing base current flag implicitly.
