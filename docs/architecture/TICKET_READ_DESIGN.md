Add optional q (trimmed, at most200 UTF-16 units before trimming, no Unicode Cc control characters) and page/pageSize (canonical decimal query strings or integer service inputs; page1–10000, size1–100). This corrects intended existing date behavior, not a newtimezonepolicy. HTTPparser supplies1/100 defaults as well as service fallback.
