## Frozen contract

`encryptStructuredRowEvidence(evidence:unknown,context:unknown,key:string):string` and `decryptStructuredRowEvidence(envelope:unknown,context:unknown,key:string)`; outputs deeply frozen verified evidence. Inputs are snapshotted through existing descriptor-safe `copyStructuredJson` before parsing. Fixed `STRUCTURED_ROW_EVIDENCE_INVALID` failures contain no data/key/OpenSSL details.

Context is a strict version1 object: schemaVersion1, registryVersion structured-v1, mapperVersion structured-mapper-v1; dataset from seven frozen datasets; lowercase UUID rowId/documentId/jobId; documentRevision/jobRevision >=0, extractionRevision/reviewRevision >=1, all <=999999999; sourceFormat PDF/DOCX/XLSX/CSV/HTML; sourceChecksum/extractionDigest/mappingDigest/payloadDigest/planDigest lowercase SHA256; tableIndex0..999,rowIndex0..9999,tableFirstRow/sourceRow1..1048576,coordinateKind WORKSHEET_CELL/CSV_RECORD/EXTRACTED_LOGICAL. sourceRow=tableFirstRow+rowIndex.

Evidence is exactly `{schemaVersion:1,payload,fields,sourceLocation,sourceUrl}`. Payload validates against the selected registry and supplied payloadDigest. Fields contain each registered field exactly once, as strict CELL `{kind,field,columnIndex,sourceColumn,extractedValue,transform,blank}` or CONSTANT `{kind,field,value,note}` from mapper output. At least one nonnullable CELL is mandatory. Recompute CELL values using existing named transform, check transform/type/null compatibility, source columns against location bounds; compare every resulting value to validated payload. CONSTANT note is reviewed nonempty/wellformed/control-free <=500 and value equals payload. Source row/table/format/location/coordinate kind agree; CSV/XLSX source range matches firstRow and contains sourceRow. Logical PDF/DOCX/HTML rows remain <=100000. sourceUrl uses existing private URL shape (https,<=2048,nullable); HTML location sourceUrl equals private sourceUrl. These URLs are retained privately, not certified safe for browser disclosure.

AES-256-GCM, fresh12-byte nonce,16-byte tag, canonical base64url `sr1.nonce.tag.ciphertext`. HKDF-SHA256 uses existing canonical32-byte base64 master key, salt yru-helpdesk-v1, info knowledge-structured-row-evidence:v1. AAD contains domain yru:structured-row-evidence:v1 and the entire checked context, including identities/versions/revisions/hashes/coordinates. No key comes from an HTTP input. Evidence JSON <=1MiB/4096 nodes; descriptor copy rejects proxies/accessors/cycles/nonfinite/bad Unicode/oversize before serialization. Ciphertext bound and canonical segments are checked before crypto; fatal UTF8 decode, then same evidence validation and freezing after authenticated decryption. Bound fits existing evidence_encrypted1398200-character schema limit.

Authentication protects the encrypted content/context under a backend key. It does not prove that caller-supplied digests describe retained originals, that a review was approved, that data is current/authorized, or that public rows/receipt agree. Future atomic preparation must derive context from actual mapper/source/review; live publication/retrieval must re-read canonical rows and effect proof. This unused component does not execute that future contract.
