This document freezes behavior, not acceptance.

## User workflow

Upload or paste official URL → read the new source automatically → review a prepared summary → fix uncertain information → save and explicitly review version/action and text plan → deliberately approve. File provenance is optional at upload and explained as needed for public student answers. Duplicate upload opens an existing extraction; it must not automatically reanalyze or disturb review/publication history. Automatic analysis of a newly created job requires a valid independent null publication receipt first. Failed receipt or analysis leaves the original available and an explicit retry.

Review starts with suggested fields for a new unsaved draft, keeping a separate empty baseline so suggestions can be saved. A saved draft always wins; refresh, edits, stale extraction, failed assistance or new observations never overwrite human values. Assisted proposals are bound to exact job/extraction revisions, private, read-only and schema-validated. Assistance cannot set actions/targets/relationships, attestations, warning dispositions or chunk consent. No new migration, model downloads, paid/unknown inference or auto-publication.

## Evidence and defaults

`GET /api/knowledge/imports/[id]/assistance` returns `{assistance:{jobId,jobRevision,extractionRevision,metadata,origins,families,departments}}`. Active SUPER_ADMIN and verified session precede path/query/private work. No query selectors. Metadata is the existing complete nullable review metadata shape, with `newFamily:null`; no review state is returned. Origins whitelist populated field paths with `EXTRACTED`, `CLASSIFIED` or `DEFAULT` and short fixed Thai labels; no copied sensitive snippets, source bodies, credentials or arbitrary model content. Actual families/departments come from reference rows, not invented codes. Final SQL snapshot confirms job/latest extraction revisions under existing authorization/timeout/share-lock wrapper. No external work in SQL.

Extract title, uniquely classified family/type/department (only existing reference codes), explicit unambiguous academic year/version, retained official source URL, and explicitly labelled published/effective dates. Dates accept exact ISO or Thai month names and Thai/Arabic digits with explicit Buddhist/Common Era conversion and civil-date validation. Collect candidates across all extracted pages; conflicting or malformed labelled evidence leaves the field null. Never substitute upload time, academic year, an unrelated date or a generic announcement date for effective date. Invalid effective intervals clear the proposed end date and remain human work. Generic classification and owner proposals are marked suggestions, never proof of authority.

Operational defaults only: `versionStream=main`, `storageMode=RAG`, `visibility=INTERNAL`. These choices are displayed and editable; internal documents are not student-answer knowledge. No default audience/student type, authority, published/effective date or PUBLIC visibility. Source authority uses the master's labelled 100/90/80/70/50 choices with custom existing numeric values preserved. No automatic declaration of official authority. Absent fields remain explicit uncertainty. The existing immutable analyzer format/date-null history remains readable; assistance adds proposals without rewriting prior extraction/history.

## Review interface

Operate mode, incumbent Thai minimal design. Start with short progress guidance and a prepared summary including visibility/source and proposal origins. A compact list states exactly which required metadata remains missing. Core editing uses actual named family/department options and document-type/authority choices; custom existing values remain accessible, including new family codes. Optional scope/year/stream/end-date/dataset/source-page settings are progressively disclosed. Required missing fields and unresolved quality/privacy warnings stay discoverable; do not hide blockers in an anonymous advanced accordion. Show the five explicit review attestations and precise unresolved warning handling. Move version and chunk panels after metadata, preserving all revision/ownership/receipt/pending/CAS gates. Preserve incomplete private save and all correction/conflict/original download capabilities.

A suggestion is not a completed review. No numerical confidence fabricated from keyword rules; distinguish extracted, classified and operational defaults. Do not claim remote AI inference. Future free-generation assistance, if needed for genuinely ambiguous material, must retain FREE_ONLY, provenance and explicit human confirmation; it is not this acceptance claim.
