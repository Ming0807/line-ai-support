# ADV-03A — scoped Activities and safe Logs

Root,8October2026; CH015/016/017/031/060, original §§30–31 and master §§15/16/31/60. [System](YRU_V1_DESIGN.md), [protocol](../agents/WORKING_PROTOCOL.md). Human requests continuous V1 and minimal approved UI. Existing private activities/AI errors/delivery attempts are real data; external OC controllers are fixture-only. This slice accepts explicit read contracts, no inferred endpoints or raw metadata.

`GET /api/activities` requires active staff. SUPER_ADMIN reads the global journal; other staff read only ticket-linked journal rows that pass `private.can_access_scope(ticket.department_id,ticket.sensitive_level)`. Filters never widen scope, counts/pages share one statement snapshot. Return only id, occurredAt, fixed action/actionLabel, actorDisplayName, ticketCode, departmentLabel and a fixed summary; never metadata, message body, reason, actor ID, LINE identity or source secrets. Map known backend ticket actions to TAKEOVER/REPLY/REASSIGN/RESOLVE/CLOSE/REOPEN/CREATE, publication to APPROVE_KNOWLEDGE, other import/provider actions to fixed groups, unknown to OTHER. Labels are server-owned; unknown action contents are not echoed.

`GET /api/logs` requires active SUPER_ADMIN before selectors. Return safe AI provider errors and LINE delivery observations only in this slice: id, loggedAt, fixed code/label, component ai-gateway or line-delivery, ERROR/WARN/INFO, observed httpStatus ornull, correlationId:null. No raw error/message/stack/request/body/URL/LINE IDs/provider tokens or generation content. Provider codes are schema-enforced operational types; unknown LINE error strings become LINE_DELIVERY_FAILED. An observed200 is a transport observation, not overall model health/quota. Queue/import log sources are a subsequent contract; don't invent them from fixture vocabulary.

Both accept strict unique allowlisted q/from/to/page/pageSize plus action (Activities), severity/component/code (Logs). Literal search escapes wildcard characters. Civil dates validated; from<=to, bounded90-day range, default last7 Bangkok civil dates; if only one endpoint supplied derive the missing7-day endpoint. Return `{items,pagination,window}` with page1..10000, size1..100(default25), total/totalPages/hasNext/hasPrevious and `{from,to,timeZone:'Asia/Bangkok'}`. Valid out-of-range pages are empty with truthful totals. Unknown/duplicate/noncanonical/invalid input fails400. Authentication401, inactive404, role403, backend503; all handled responses private/no-store, VaryCookie/nosniff and fixed errors.

Root owns SQL/auth/privacy and pure browser DTO validation. Current actor/grants lock for the transaction, statement5s/lock2s. No schema change required. UI receives real SSR rows and browser loaders through these exact accepted envelopes only after root integration; accepted contract is not live browser proof.
