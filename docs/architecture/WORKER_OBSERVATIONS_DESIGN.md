Add one private fixed infrastructure table `private.worker_observations`: `worker text PRIMARY KEY CHECK(worker IN('INBOX','OUTBOX','AI','INCIDENT'))`, `observed_at timestamptz NOT NULL DEFAULT clock_timestamp()`. No instance/PID/host/session/queue payload or credentials. RLS enabled, PUBLIC/anon/authenticated revoked; service_role SELECT/INSERT and UPDATE(observed_at), no DELETE or key UPDATE. Four rows maximum, no per-run/year/document schema or cleanup jobs. Backend writes use database clock and atomic upsert; callers cannot supply timestamps. No browser mutation endpoint.

`lib/operations/worker-observations.ts` exports the four worker codes and a validated `recordWorkerObservation(pool,worker)` promise. `createWorkerObserver(pool,worker,options?:{now?:()=>number})` returns an async check-in function, using monotonic `performance.now` by default: first call writes, later writes at most once per30seconds; failure logs only fixed `WORKER_OBSERVATION_FAILED` and does not suppress business queue work.30seconds is an engineering write-rate limit, not a healthy/stale threshold. No error object/query/connection/keys logged. No timers, extra worker loop or HTTP introduced.

Each configured entrypoint calls its observer before its existing loop cycle, including `--once`. The disabled AI entrypoint creates no observation. Graceful exit retains the last observation; it does not label all worker processes stopped. A hung cycle stops making new observations, but the API does not infer a process status from age. Existing lease/delivery/business ownership checks remain unchanged.

SUPER_ADMIN Settings appends `workerObservations` with exactly four `{worker,lastObservedAt:string|null}` records. Dates are observed database timestamps and cannot be in the future relative to the settings observation. Missing data stays null. Retain `workerLiveness:'UNKNOWN'`: a check-in proves one configured process reached the loop, not current health, successful queue processing, LINE delivery or all-instance liveness. The UI says “พบการทำงานล่าสุด”/“ยังไม่มีข้อมูลการทำงาน” and shows Bangkok date/time; no green/healthy state, invented freshness threshold or identities. Non-super/inactive/anonymous roles remain denied before private reads.
