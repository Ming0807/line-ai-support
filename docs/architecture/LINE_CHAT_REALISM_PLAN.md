## ข้อเสนอ เรียงตามผลต่อผู้ใช้

### แก้ (ปัญหาจริง)

1. **CONV-BURST-01 หน้าต่างรวมข้อความแบบปรับตามข้อความ**: ช่วงเงียบปกติ ~2.5 วินาที ถ้าข้อความล่าสุดดูยังไม่จบ (ทักทายอย่างเดียว, สั้นมาก, "ขอถามหน่อย", "คือ") รอได้ถึง ~8 วินาที เพดานรวม ~15 วินาที แสดง loading ทันทีที่ได้ข้อความแรกเพื่อให้รู้ว่าบอทกำลังฟัง ต้องมี migration เปลี่ยน check 3 วินาที ตัวตัดสิน "ยังไม่จบ" เป็นกฎ deterministic ที่มีผลแค่ระยะเวลารอ ไม่ใช่ตัวตัดสินความหมาย
2. **CONV-SUPERSEDE-01 ข้อความใหม่ชนะคำตอบเก่า**: ถ้ามีข้อความ USER ใหม่ใน conversation เดียวกันก่อนคำตอบเก่าถูกส่ง (job ยัง PENDING หรือยังไม่เข้า outbox) ให้ปิด job เก่าเป็น SUPERSEDED และ job ใหม่รับข้อความผู้ใช้ทั้งหมดที่ยังไม่ได้ตอบตั้งแต่คำตอบ AI ล่าสุดที่ SENT. คำตอบที่เข้า outbox แล้วไม่ดึงกลับ. idempotency/lease/delivery fence เดิมคงไว้ ต้องมี owned-PG test เรื่อง race
3. **CONV-GREET-01 ทักทายอย่างเดียวไม่ต้องเรียก model**: ถ้าทั้ง turn เป็นคำทักทาย/ขอบคุณสั้นๆ และไม่มีข้อความตามมาในหน้าต่างที่ขยายแล้ว ตอบด้วยข้อความสั้นแบบ deterministic พร้อม quick reply หัวข้อยอดนิยม 3 ปุ่ม ประหยัด quota และไม่ชนกับคำถามที่ตามมา

### ปรับ

4. **CONV-STYLE-01 รูปแบบคำตอบ**: สั้น เป็นข้อ 1. 2. 3. ภาษาสุภาพแบบคุย ไม่เกิน ~8 บรรทัดในข้อความแรก; ตีความคำสั้น/พิมพ์ผิดแบบเป็นมิตร; ถ้ามีค่า default ที่สมเหตุผล (ภาคปกติ ปีการศึกษาปัจจุบัน) ให้ตอบก่อนแล้วบอกเงื่อนไข แทนการถามกลับ ยกเว้นข้อมูลทางการที่ต่างกันจริงตาม scope
5. **CONV-EVAL-LINE-01 ชุดทดสอบแบบ LINE จริง**: ~40 กรณี ได้แก่ คำถามสั้น, พิมพ์ผิด, ภาษาพูด, ส่งเป็นช่วง, ทักทายแล้วถาม, เปลี่ยนเรื่องกลางคัน, ข้อความหลังคำตอบ ("ยังไม่ได้", "แล้วถ้า...") ใช้กับ fake provider ได้ทันที และวัดกับ Gemini จริงเมื่อผู้ใช้อนุมัติงบ (ประมาณ ≤ 240 calls ต่อรอบเทียบ)
6. **ใช้ CONV-V2 เป็นค่า default** เมื่อผ่านเกณฑ์ใน CONV-V2 หัวข้อ 7 และชุด 5 แล้ว

### เปลี่ยน

7. **ลำดับความสำคัญ**: เพิ่มข้อมูลจริงให้ AI (OCR-IMP-01 + ตรวจเอกสารที่นักศึกษาถามบ่อยก่อน) และแก้ 1–3 ก่อนงาน UI/ระบบเสริมอื่น เพราะคุณภาพคำตอบขึ้นกับข้อมูลและการรับข้อความเป็นหลัก

### ทิ้ง/พัก

8. หลัง V2 ผ่านเกณฑ์และผู้ใช้ทดสอบบน OA จริงแล้ว ให้ถอด flow เดิม 6 ขั้นออก ไม่ดูแลสองทางยาวๆ
9. พักงานเสนอ web search cascade, งานขัด UI รอบเพิ่ม และการปรับแต่ง Hermes build ไว้หลังแชตหลักใช้งานได้ดี
10. เลิกส่งคำตอบแบบเอกสารยาวหลายข้อความ (แทนด้วย short-first ที่มีอยู่แล้ว)

## สถานะ 16 พ.ย. 2026 (DEC-206)

- ข้อ 1 CONV-BURST-01 ทำแล้ว: ปกติรอเงียบ 2.5 วินาที ข้อความที่ดูยังไม่จบรอ 8 วินาที เพดาน 15 วินาที (migration 57) และเริ่ม loading ตั้งแต่ข้อความแรกของหน้าต่าง
- ข้อ 2 CONV-SUPERSEDE-01 ทำแล้ว แต่ต่างจากที่เขียนไว้ด้านบน: โค้ดเดิมปิดคำตอบเก่าที่ยังไม่ส่งอยู่แล้ว (`eligibleAIJob` และ `STALE_AI_INPUT` ใน outbox) ส่วนที่ขาดคือ job ใหม่ตอบเฉพาะหน้าต่างตัวเอง ตอนนี้ job ใหม่รวมข้อความที่ยังไม่มีคำตอบ (ไม่เกิน 10 ข้อความ / 10 นาที) เข้าเป็นคำถามเดียว
- ข้อ 3 CONV-GREET-01 ทำแล้ว: ทักทาย/ขอบคุณอย่างเดียวตอบด้วยข้อความคงที่ ไม่เรียก model ทักทายมีปุ่มหัวข้อ 3 ปุ่ม
- ยังไม่ได้ทดสอบกับ LINE จริง ต้องให้ผู้ใช้ทดสอบบน OA (CONV-V2-07)

## ลำดับทำ

OCR-IMP-01 (อนุมัติแล้ว) → CONV-BURST-01 + CONV-SUPERSEDE-01 + CONV-GREET-01 (RED test ก่อน, owned-PG) → CONV-EVAL-LINE-01 ด้วย fake provider → ขออนุมัติงบ Gemini สำหรับ CONV-V2-00/06 + ชุด LINE → เปลี่ยน default → ผู้ใช้ทดสอบบน OA จริง (CONV-V2-07)
