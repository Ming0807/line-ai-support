คำศัพท์ที่ใช้ใน LINE webhook

คำความหมายในโปรเจกต์เรา
WebhookLINE ส่ง event มาที่ URL ของ backend อัตโนมัติ
POSTวิธีส่งคำขอพร้อม body มายัง endpoint
Raw bodyข้อมูลต้นฉบับก่อนแปลงเป็น object ต้องใช้คำนวณลายเซ็น
Payloadข้อมูลที่มากับคำขอ เช่น events และข้อความ
Channel Secretค่าของ LINE channel ใช้ตรวจลายเซ็น เก็บใน .env ของ server
x-line-signatureลายเซ็น HMAC-SHA256 แบบ base64 ที่ส่งมาใน header
JSON.parseแปลงข้อความ JSON เป็น object หลังตรวจลายเซ็นแล้ว
HTTP 200backend ตอบว่าได้รับคำขอสำเร็จ ไม่ใช่ข้อความตอบนักศึกษา
