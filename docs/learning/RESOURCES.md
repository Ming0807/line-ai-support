# LINE webhook resources

## Knowledge

- [LINE: Verify webhook signature](https://developers.line.biz/en/docs/messaging-api/verify-webhook-signature/)
  วิธี HMAC-SHA256 และเหตุผลที่ต้องใช้ body ต้นฉบับก่อนแปลง JSON
- [LINE: Receive messages](https://developers.line.biz/en/docs/messaging-api/receiving-messages/)
  การส่ง event, การตอบรับ webhook และการทดสอบ events ว่าง
- [Next.js: Route handlers](https://nextjs.org/docs/app/getting-started/route-handlers)
  ความสัมพันธ์ของ app/**/route.ts กับ URL และฟังก์ชัน POST
