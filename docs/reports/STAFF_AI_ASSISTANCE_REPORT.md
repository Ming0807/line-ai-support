# ADV-05A — on-demand HUMAN staff assistance

8 October 2026, root implementation/integration; baseline `bad2a29` plus this explicitly staged slice. Original overview §14, master §52, CH052/USR-STAFFASSIST; [design](../architecture/STAFF_AI_ASSISTANCE_DESIGN.md), [execution](../superpowers/plans/2026-10-08-yru-staff-ai-assistance.md).

Authenticated staff can request case/conversation summaries, an editable reply draft and department/priority recommendations for a currently accessible active HUMAN ticket. The existing registry gateway and its persisted cost policy apply; startup remains FREE_ONLY. Advice is ephemeral. Generation cannot accept, resolve, route, alter priority or enqueue a Student reply. Draft insertion is a separate action, confirms replacement of nonempty composer text and leaves the existing authorized STAFF_REPLY action responsible for sending.

The provider receives only bounded case text, newest selected messages and active department names/codes. Explicit technical LINE/session/message identities, anonymous codes and staff names are excluded. User-authored text may itself contain private information; this is minimization, not a claim of automatic redaction of all sensitive free text. The service commits its authenticated snapshot before provider HTTP, then rechecks the actor/grants/scope/HUMAN state/revisions and a digest of all selected source records. Changed source or revoked access discards advice. Strict output rejects tools and unknown department suggestions. The private API accepts revision only, with same-origin authentication, bounded strict UTF-8 JSON and fixed errors.
