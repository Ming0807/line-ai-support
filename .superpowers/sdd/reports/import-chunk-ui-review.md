## Findings and resolution status

- **P2 acknowledgment-clear race — resolved in current source.** During the initial review, the “withdraw saved acknowledgment” button was active while the parent review was saving or reloading. With a persisted v2 acknowledgment and no loaded plan, clicking it could clear the local draft while the request was in flight, then the successful response could replace that draft and restore the acknowledgment. Current `chunk-plan-panel.tsx:164` disables the action while `disabled || pending`; the parent passes its save/load lock through `disabled`. The recovery copy now says the old acknowledgment has not yet been compared with the current sample, avoiding a false claim that the extraction differs. Panel-level error recovery leaves withdrawal available. Root reports a held-PUT browser regression covering this; this reviewer did not run the browser suite.
- **Keyboard access to long chunk text — resolved in current source.** The preview was initially an overflowing `<pre>` without explicit keyboard focus or a name. It is now `tabIndex={0}`, `role="region"`, and has an item-specific `aria-label` (`chunk-plan-panel.tsx:149`), so keyboard users can focus the scrollable text and identify it.
- **Parser warning codes in user-facing copy — resolved in current source.** The warning list initially rendered the enum code. `chunk-plan-panel.tsx` now maps all nine accepted parser warning codes to Thai-readable primary labels and renders `warningLabels[warning.code]` (`chunk-plan-panel.tsx:22,157`).

The response validator checks the exact envelope and four echoed counters, job/extraction plan binding, schema/chunker, pinned model/revision/fingerprint, digest shape, nonempty bounded chunk list, text/token bounds, warning enum/count bounds, and strict fields/bounds for all five location variants. The parent keys the panel by job/extraction/review revisions and reset epoch; preview lookup is same-origin/no-store and uses abort, serial, mount, and tuple guards. Only deliberate checkbox changes set the v2 digest; the initial v1/current draft has no acknowledgment selected. Chunk lookup pending joins the parent dirty/pending lock, save requires an explicit user action, and accepted save/reload resets the panel. Recovery retains the parent draft and allows retry or clearing a stored acknowledgment when the panel itself is in an error state. Pagination and coordinate labels wrap in the narrow-screen CSS rules. These are source findings only; the browser/visual behavior below is root-owned.
