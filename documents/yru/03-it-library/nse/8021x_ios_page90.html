การเชื่อมต่อ YRU-802.1X(IOS (iPhone, iPad))

4 เมษายน 2565 (Root) ระบบเครือข่ายไร้สาย (YRU-WiFi)

IOS (iPhone, iPad )

การเชื่อมต่อ YRU-802.1X สำหรับ ระบบปฏิบัติการ IOS  (iPhone, iPad และ iPod touch)

  1. เปิด WiFi ในเครื่อง  ไปที่ Setting 

     
  2. ค้นหาสัญญาณ : YRU-802.1X หรือ YRU-802.1X(Dorm)

     
  3. เชื่อมต่อสัญญาณ YRU-802.1X หรือ YRU-802.1X(Dorm)

     
  4. ลงชื่อเข้าใช้งานอินเทอร์เน็ตในช่อง
    ใส่ Username Password

    Username : ผู้ใช้งานอินเทอร์เน็ต  (ใช้บัญชีผู้ใช้งานเดียวกับระบบ passport.yru.ac.th)
    Password : รหัสผ่านในการเข้าใช้งานอินเทอร์เน็ต  (ใช้บัญชีผู้ใช้งานเดียวกับระบบ passport.yru.ac.th)
    กดปุ่ม Join

  5. จะขึ้นหน้าจอให้ยืนยัน Certificate   กดปุ่ม  Accept
  6. แสดงสถานะการเชื่อมต่อเรียบร้อยแล้ว
