# รายงานการค้นหาเอกสารทางการ YRU: IT และห้องสมุด

วันที่ตรวจและจัดเก็บ: 4 ตุลาคม 2569 (เวลาไทย, UTC+07:00)  
ขอบเขต: หน้าและเอกสารสาธารณะจากงานระบบเครือข่าย/ศูนย์คอมพิวเตอร์ YRU, ศูนย์บรรณสารสนเทศ YRU และหน้าที่เชื่อมโยงโดยตรงจากเว็บไซต์ทางการ

## สิ่งที่จัดเก็บ

manifest.json มีเอกสารที่ดาวน์โหลดสำเร็จ 21 รายการ: snapshot HTML 19 รายการ และ PDF จริง 2 รายการ พร้อมไฟล์ข้อความ UTF-8 แยกสำหรับค้นอ่านได้ ทั้งหมดมี review_status=PENDING_REVIEW และ is_current=null; ยังไม่มีรายการใดได้รับอนุมัติให้ใช้ตอบผู้ใช้หรือเข้า public RAG. failed-source-attempts.json แยกบันทึกความพยายามที่ไม่ได้ไฟล์ 2 รายการ โดยไม่แทนหน้าผิดพลาดเป็น PDF.

เอกสารครอบคลุม YRU-WiFi, ลงทะเบียน MAC, YRU-802.1X (Android/iOS/Windows), การแก้ปัญหาเครือข่าย, YRU Passport, การสมัครอีเมล Microsoft (กล่าวถึงเพียงสั้น ๆ), เวลาทำการ/ติดต่อห้องสมุด, บริการและการจองห้อง, แบบฟอร์มสมาชิก และระเบียบ/แนวปฏิบัติห้องศึกษาค้นคว้า. PDF แนวปฏิบัติใช้ห้องเป็นเอกสารสแกน จึงแนบข้อความถอดจากภาพที่ทำเครื่องหมาย partial เพื่อให้ค้นได้ และต้องตรวจเทียบกับต้นฉบับก่อนนำไปใช้.

| Family | สิ่งที่เก็บได้ | สถานะ web-only / เอกสารเก่าที่ต้องระวัง |
|---|---|---|
| WIFI_GUIDE | HTML snapshot 11 หน้า พร้อม text extract | ทุกขั้นตอนที่เก็บเป็นหน้าเว็บ ไม่พบคู่มือ PDF ปัจจุบัน; หลายหน้าลงวันที่ 2563–2565 และต้องตรวจค่าตั้งค่าก่อนใช้ |
| YRU_PASSPORT_GUIDE | HTML snapshot 2 หน้า พร้อม text extract | คู่มือ PDF จาก Drive ต้อง sign-in; บทความปี 2566 ที่มีขั้นตอนเก่าและค่าเริ่มต้นเป็นเลขบัตรประชาชนต้องกักไว้รอยืนยัน |
| MICROSOFT_365_GUIDE | สำเนา HTML ของข้อความกล่าวถึง Microsoft (O365) พร้อม text extract | เป็นเพียงเมนูสมัครและโดเมน @ms.yru.ac.th; ไม่พบคู่มือ Microsoft 365 เฉพาะทาง |
| LIBRARY_GUIDE | HTML snapshot 5 หน้า และ PDF จริง 2 ไฟล์ พร้อม text extract | มีหน้าติดต่อ/บริการเว็บปัจจุบัน แต่กฎยืมคืนปี 2562 และ PDF ระเบียบปี 2564 เก่า; ไม่พบไฟล์คู่มือจองห้องที่ข่าวอ้างถึง; ค่าธรรมเนียมในแหล่งต่างกัน |

## ผลการตรวจและ flags สำคัญ

- **YRU Passport — ยังขาดขั้นตอนกู้บัญชี/ลืมรหัสผ่านฉบับปัจจุบัน:** [หน้าบริการ Passport ของ NSE](https://nse.yru.ac.th/page/86/%E0%B8%A3%E0%B8%B0%E0%B8%9A%E0%B8%9A%E0%B8%88%E0%B8%B1%E0%B8%94%E0%B8%81%E0%B8%B2%E0%B8%A3%E0%B8%9A%E0%B8%B1%E0%B8%8D%E0%B8%8A%E0%B8%B5%E0%B8%9C%E0%B8%B9%E0%B9%89%E0%B9%83%E0%B8%8A%E0%B9%89%E0%B8%87%E0%B8%B2%E0%B8%99%E0%B8%A3%E0%B8%B0%E0%B8%9A%E0%B8%9A%E0%B8%AA%E0%B8%B2%E0%B8%A3%E0%B8%AA%E0%B8%99%E0%B9%80%E0%B8%97%E0%B8%A8_(YRU_Passport).html) ลิงก์คู่มือ Google Drive ต้องลงชื่อเข้าใช้และบันทึกไม่ได้. [บทความ Passport ปี 2566](https://nse.yru.ac.th/page/92/YRU-Passport_%E0%B8%9A%E0%B8%A3%E0%B8%B4%E0%B8%81%E0%B8%B2%E0%B8%A3%E0%B8%9A%E0%B8%B1%E0%B8%8D%E0%B8%8A%E0%B8%B5%E0%B8%9C%E0%B8%B9%E0%B9%89%E0%B8%8A%E0%B9%83%E0%B8%8A%E0%B9%89%E0%B8%87%E0%B8%B2%E0%B8%99%E0%B8%A3%E0%B8%B0%E0%B8%9A%E0%B8%9A%E0%B8%AA%E0%B8%B2%E0%B8%A3%E0%B8%AA%E0%B8%99%E0%B9%80%E0%B8%97%E0%B8%A8%E0%B8%A0%E0%B8%B2%E0%B8%A2%E0%B9%83%E0%B8%99%E0%B8%A1%E0%B8%AB%E0%B8%B2%E0%B8%A7%E0%B8%B4%E0%B8%97%E0%B8%A2%E0%B8%B2%E0%B8%A5%E0%B8%B1%E0%B8%A2%E0%B8%A3%E0%B8%B2%E0%B8%8A%E0%B8%A0%E0%B8%B1%E0%B8%8F%E0%B8%A2%E0%B8%B0%E0%B8%A5%E0%B8%B2.html) ระบุให้ใช้เลขบัตรประชาชนเป็นรหัสเริ่มต้น จึงทำเครื่องหมายเป็น **ข้อมูลเก่า/เสี่ยง ห้ามแนะนำจนกว่าเจ้าหน้าที่ IT จะยืนยัน**. [หน้าช่วยเหลือการเข้า Wi-Fi](https://nse.yru.ac.th/page/115) ระบุให้ติดต่อ 073-299676 หรือ OSS เมื่อเข้าไม่ได้ แต่ไม่ได้ให้ขั้นตอนรีเซ็ตรหัสผ่าน. การดึงหน้า portal โดยตรงวน redirect ไป auth/login; ไม่พบขั้นตอนกู้บัญชีสาธารณะที่ตรวจสอบได้.
- **Microsoft 365 — ยังขาดคู่มือเฉพาะทางฉบับปัจจุบัน:** ในหน้าทางการที่ตรวจพบ มีเพียงบทความ Passport ข้างต้นกล่าวถึงเมนูสมัคร Microsoft (O365) และโดเมน @ms.yru.ac.th; ไม่พบคู่มือ sign-in, activation, MFA, license หรือ recovery จาก ARITC/NSE. เก็บสำเนาหน้านั้นไว้ในหมวด MICROSOFT_365_GUIDE เพื่อบันทึกหลักฐานการกล่าวถึงเท่านั้น; อย่าแสดงเป็นคู่มือครบขั้นตอน.
- **Library — มีข้อมูลบริการปัจจุบันบางส่วน แต่กฎยืมคืนปัจจุบันยังไม่พบ:** [หน้าติดต่อ](https://library.yru.ac.th/contact) ให้เวลา จ.–ศ. 08:00–17:00, ส.–อา. 08:30–16:30, ปิดวันหยุดนักขัตฤกษ์ และ 073-299675 ต่อ 23300. [หน้าบริการ](https://library.yru.ac.th/service/) และ [ข่าวจองห้อง (2567)](https://library.yru.ac.th/view/1655) ให้ช่องทางบริการและลิงก์ ebooking.yru.ac.th; ไม่พบไฟล์คู่มือจองห้องที่ข่าวอ้างถึง. ข้อมูลกฎยืม จำนวนเล่ม/วัน และค่าปรับที่พบอยู่ในหน้าเว็บวันที่ 2 ส.ค. 2562 จึงทำเครื่องหมายเก่า. แบบฟอร์ม PDF ระบุค่าบำรุงรายปี 200 บาท/บัตร 50 บาท/ประกัน 500 บาท ขณะที่หน้า legacy ระบุค่าธรรมเนียมเป็นรายภาคเรียน — **ข้อมูลขัดกัน ต้องขอห้องสมุดยืนยัน**. PDF แนวปฏิบัติห้องศึกษาค้นคว้าปี 2564 ยังอ้าง booking.yru.ac.th ซึ่งต่างจากข่าวปี 2567 ที่ใช้ ebooking.yru.ac.th.
- **Wi-Fi / 802.1X — มีขั้นตอนแต่หลายหน้าลงวันที่ 2563–2565:** รวมถึงการลงทะเบียน MAC, การเชื่อมต่อ และหน้าจอตั้งค่าเฉพาะระบบปฏิบัติการ. ให้เจ้าหน้าที่เครือข่ายทวน SSID, certificate/PEAP, การลงทะเบียนอุปกรณ์ และหน้าจอระบบปฏิบัติการก่อนใช้เป็นคำตอบขั้นตอน เนื้อหาเก่าไม่เท่ากับขั้นตอนปัจจุบัน.
- **แบบฟอร์มสมาชิกห้องสมุด:** PDF เปล่ามีช่องเลขประจำตัวประชาชน ที่อยู่ โทรศัพท์ และอีเมล. อย่านำแบบฟอร์มที่ผู้ใช้กรอกแล้วหรือข้อมูลรายบุคคลเข้าชุดความรู้สาธารณะ; ไฟล์เปล่าก็ยังรอผู้ดูแลพิจารณาว่าจำเป็นต่อคำตอบสาธารณะหรือไม่.

## แหล่งที่เข้าถึงไม่ได้หรือควรคัดออก

รายละเอียด URL/ผลการเรียกอยู่ใน failed-source-attempts.json: คู่มือ Passport จาก Drive ถูกพาไปหน้า Google sign-in และ Passport portal ตอบ redirect loop จึงไม่บันทึกเป็นไฟล์. นี่คือ **ไฟล์ที่พยายามดึงแต่เข้าถึงไม่ได้**, ส่วนคู่มือ Microsoft 365 เฉพาะทางและขั้นตอน recovery ใหม่เป็น **เอกสารสาธารณะที่ยังหาไม่พบ** จากการค้นหน้า official ในขอบเขตนี้. ไม่ควรปะปนสองสถานะนี้.

ระหว่างสำรวจพบหน้า legacy ห้องสมุดบางรายการมีลิงก์ภายนอกไม่เกี่ยวข้อง/เสี่ยง (รวมลิงก์พนัน) จึงไม่นำเข้า manifest หรือชุดความรู้. ไม่ได้เก็บข่าวเก่า รายชื่อผู้เรียน หรือรายการข่าว/สถิติที่ไม่ใช่ความรู้บริการ.

## การตัดสินใจก่อนนำขึ้น RAG

ขอผู้รับผิดชอบยืนยันขั้นตอนปัจจุบันของ Passport recovery และ Microsoft 365; ขอห้องสมุดยืนยันระเบียบยืมคืน ค่าธรรมเนียม และเวลาเปิดเฉพาะกิจ; และขอทีมเครือข่ายทบทวนคู่มือ Wi-Fi/802.1X ที่ลงวันที่เก่า. จนกว่าจะผ่านการทบทวน ให้คงเอกสารทั้งหมดเป็น pending และใช้เฉพาะข้อมูลติดต่อ/ลิงก์ทางการที่ผู้ดูแลอนุมัติ.
